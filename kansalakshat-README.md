## Nirmaan OS

A mobile app that connects **builders**, **supervisors**, and their construction **sites**.

Builders create sites, generate supervisor logins, and track budget and progress.
Supervisors file daily and weekly reports covering spending, materials, labour, issues
and photos, which flow straight back to the builder as a timeline. Large touch targets
and a deliberately plain white and orange system, because it is used by people whose
job is not software.
